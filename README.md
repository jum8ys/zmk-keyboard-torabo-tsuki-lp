
[torabo-tsuki LP](https://github.com/sekigon-gonnoc/torabo-tsuki-lp)用のZMKファームウェア

* _centralがついているuf2をトラックボールがついている方に、_peripheralを反対側に書き込んでください
* キーマップはkeymap-editorおよびzmk-studioで編集できます

## キーマップ

初期配列は右トラックボール構成のS配列（42キー）です。ボールが占める右最下段の中央2位置を配列から除外しています。通常版torabo-tsukiの6レイヤーとキー操作を移植し、追加の3キー（Bの右隣、Nの左隣、右Ctrlの左隣）は未割り当てにしています。
左側または両側トラックボールで使う場合は、ボール位置に合わせた配列とキー割り当ての調整が必要です。
ZMK Studioに保存済みの設定がある場合は、書き込み後もその設定が使われるため、初期設定との違いを確認してください。

`config/keymap.keymap`またはS配列の定義をmasterブランチで更新すると、Draw Keymap Actionsが図を生成し、`keymap-drawer`へコミットするとともに成果物として保存します。手動実行もできます。

## トラックボール

PAW3222と既存の配線・カーソル方向は維持しています。感度は通常版の600 CPIに最も近い608 CPI、最上位の有効レイヤーが1のときは高解像度スクロールを有効にし、通常版の30カウントで1単位に相当するよう16/30倍で変換します。レイヤー2〜5が有効な間はカーソル移動を優先します。スクロール方向はカーソル移動に対して横は同方向、縦は逆方向です。両側トラックボール構成にも適用します。

PAW3222ドライバーの読み取り周期は15ms固定で、通常版の125Hz（8ms）には設定だけでは変更できません。また、スクロールはZMKの入力プロセッサーで余りを保持するため、通常版の閾値超過時に余りを破棄する処理とは異なります。
